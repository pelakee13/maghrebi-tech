This is my own website: a bilingual portfolio in Persian and English, designed and built by me.

Two decisions shape how it behaves. First, the language switcher keeps the visitor on the counterpart page: switching from Persian to English (or back) opens the same page in the other language, with the same layout mirrored for RTL and LTR reading. Second, the inquiry path carries the visitor's choice: choosing website design on the Services page sends the visitor to the contact form with that service already selected (`?service=website-design`), so the inquiry arrives with its context instead of a blank message.
